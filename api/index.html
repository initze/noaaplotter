    API reference¶

    A small, deliberately-focused library: one main class, a Typer CLI, and a handful of internal helpers (not a stable API).

    NOAAPlotter¶

    The plotting class — load a data file, then render the daily or monthly figures. Three methods:

    • NOAAPlotter(...) — constructor
    • plot_weather_series(...) — the daily plot (static or interactive)
    • plot_monthly_barchart(...) — the monthly bar chart
